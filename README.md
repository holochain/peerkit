# Peerkit

Peerkit is a peer-to-peer data synchronization framework. It enables developers to add decentralized data sharing to their applications.

Groups of users get full control over their data and participation. Peerkit can be integrated incrementally into existing apps, synchronizing only the data you specify.

See [SPECIFICATIONS.md](./SPECIFICATIONS.md) for the full specification.

See the [API documentation](https://holochain.github.io/peerkit/) for reference.

## Context

The Holochain Foundation's mission is to support and embody social coherence through computing frameworks that enable collective intelligence and collaboration among peers. Peerkit is an experiment. There are many valid approaches serving different constraints and audiences, and we're interested in exploring more than one of them.

Peerkit is an effort to try a different approach to P2P software: no Rust dependency, and a lighter footprint where deep validation is layered on top rather than built in from the start. It's live, usable, and something we'll continue to explore as capacity allows. It is one of what will be several experiments the foundation supports over time.

We'd love feedback and to see what people build with it.
